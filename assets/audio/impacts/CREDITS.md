# Recorded impact sounds

From **Impact Sounds** by Kenney (https://kenney.nl), released under
CC0 1.0 Universal (see `LICENSE-CC0.txt`); taken from the CC0 Godot port
https://github.com/Boyquotes/kenney-impact-sounds-for-godot. Files are unchanged.

| Use | Files |
| --- | --- |
| Crate or barrel breaking | `impact_wood_heavy_000`–`002`, layered with `impact_plank_medium_000`–`001` |
| Jar shattering | `impact_plate_heavy_000`, `impact_plate_medium_000`–`001` |
| Door slamming shut | `impact_wood_heavy_003`–`004`, with the bolt's `impact_metal_heavy_001` / `003` |
