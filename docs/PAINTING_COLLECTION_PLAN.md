Observed rights labels are source evidence, not a blanket legal guarantee. Each shipped file must have a pinned source revision, license evidence, source attribution and checksum. A museum's object-description text or modern audio commentary is separate copyrighted material: write short original factual captions instead of copying interpretive essays. None of these image candidates should be treated as already imported or release-cleared merely because it appears in this plan.

## Implementation handoff

The main [expansion plan](EXPANSION_PLAN.md) owns room sockets, discovery behavior, the fixed `world_classics_12_v1` requirement, permanent progress, unseen-first distribution and the Paint Sprayer gate. The table above is the proposed acquisition manifest, not a statement that files are already shipped. Water Lilies needs per-image verification before committing the founding collection IDs; its documented fallback is Woman with a Parasol.

For each selected file, capture the exact source record/revision, original or approved derivative URL, rights statement, retrieval date, dimensions and SHA-256. Preserve the complete composition and aspect ratio. Use original factual captions rather than copying museum essays, and include source/credit information in-game as well as in documentation.

Download approved reproductions during authoring only. Ship optimized local textures and thumbnails; do not request art over the network during play. Start with about 1024px wall textures, optional on-demand 2048px inspection images and a visible-image residency budget. Avoid downloading the approximately 664MB Starry Night original when a documented derivative is sufficient. Use Godot's import settings for size limits, mipmaps and mobile texture compression; do not recolor or generate replacements for the artworks.

Before the first release of the collection, freeze the selected twelve stable IDs. After that release, changing a reproduction file or its resolution must not change the painting's identity, and future collections must not enlarge this weapon's original requirement.
